---
name: reverb3
params: [audio, time, diffusion, damping_cutoff]
arities: [4]
variadic: false
receives: signal
returns: signal
---

Allpass-loop reverb,
with no room size — just `time` to -60 dB,
`diffusion` in 0..=1,
and a `damping_cutoff` in hertz applied to each loop pass.
Wet only.
All parameters except the audio input are constants.
