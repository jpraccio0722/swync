name: env
params: [attack, decay, sustain, release, duration]
arities: [5]
variadic: false
receives: number
returns: signal
---

Time-based ADSR for one-shot voices.
Attack,
decay and sustain fill `duration`; the release starts where that ends and rings on for its own time past it,
so the note is held for `duration` and the voice lasts `duration + release`.
Pass the voice-bound `dur` as the duration — `legato` shortens the held part and leaves the release alone.
All arguments are constants.
