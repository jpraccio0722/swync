---
name: list
params: [number]
arities: [1]
variadic: true
receives: number
returns: lane
---

Marks numbers as one value rather than a sequence. A lane is read by note — the
nth note takes the nth value, wrapping — so `div: [2, 3]` gives the first note 2
and the second 3, where `div: list(2, 3)` gives every note both. `'[2, 3]` is the
same value written short. Only a lane reads one.

```swync
fn poly(n, div = [4]) = for d in div { saw(n * d) * 0.3 }

play([110, 165], poly, div: list(2, 3))
```

The quote spelling is the one to reach for inside a lane that is already
bracket-heavy:

```swync
play([110, 165], poly, div: ['[2, 3], '[4], `])
```
