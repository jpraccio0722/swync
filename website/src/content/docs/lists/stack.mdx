---
name: stack
params: [pattern]
arities: [1]
variadic: true
receives: pattern
returns: pattern
---

Patterns that sound at once instead of in turn: `stack([c4;2, e4;2], [g4;4])` is a two-note line under a held g.
Each argument keeps its own division,
so the layers need not agree on a rhythm — a three against a four is written by stacking them.
This is how a chord is written,
and how a drawn part with overlapping notes is split into voices.
Lanes read a stack as all its values in order,
layer by layer.
