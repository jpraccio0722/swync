---
name: dot
params: [value, dots]
arities: [1, 2]
variadic: false
receives: duration
returns: duration
---

Dot a written note value: `q.dot` is a dotted quarter,
a quarter and an eighth.
`dots` defaults to 1; `q.dot(2)` is the doubly-dotted quarter,
which is a quarter and an eighth and a sixteenth.
Written as a count rather than by repeating `.dot`,
because each dot adds half of the note itself rather than half of what the last one left.
