---
name: bend
params: [device, channel, lo, hi]
arities: [1, 2, 4]
variadic: false
receives: number
returns: signal
---

The pitch wheel as a signal, -1 to 1 with the wheel at rest reading 0 — so
`note + bend("keys", 1, -2, 2)` bends two semitones either way.

Give a range to change that. Smoothed like `cc`.
